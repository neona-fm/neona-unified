3. Сетевой движок

Официальный sing-box 1.14.4. Загружается один раз с GitHub, контрольная сумма проверяется. Можно импортировать тот же официальный ZIP вручную.

При первом подключении выключи в Hiddify и Xray режимы VPN/TUN/системного прокси, чтобы они не конфликтовали с нашим клиентом. Подписку сначала можно импортировать в твоей текущей рабочей связке.
