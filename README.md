# Neona Unified · VPN + Windows MCP + Chrome MCP

**Neona Unified 1.3** — единое графическое приложение для Windows 10/11 x64, которое запускает VPN с раздельной маршрутизацией и два защищённых туннеля MCP последовательно, по одной кнопке.

> **Статус:** 1.3 подтверждена автором проекта в реальной работе на Windows 17 ноября 2026 года. Программа создавалась и проверялась на конкретной конфигурации; универсальная совместимость с каждым VPN-провайдером и окружением не гарантируется.

В архиве `NeonaUnified.exe`, исходный код Go и исходная русская документация. Само окно программы написано на Go: **Python для запуска GUI не нужен**. ## Что делает программа

1. Читает сохранённую VPN-подписку, позволяет выбрать совместимый узел.
2. До изменения системных маршрутов тестирует VPN-сервер, затем запускает Xray с Windows TUN.
3. Проверяет, что системный зарубежный IP действительно используется, а российский сайт доступен напрямую.
4. Только после подтверждения VPN последовательно запускает **Windows MCP** и затем **Chrome MCP**, дожидаясь установления связи при старте.
5. После успешного запуска **не выполняет периодические проверки VPN/MCP, не перезапускает туннели автоматически и не показывает бесконечные всплывающие предупреждения**. Ручные проверки доступны по кнопке.

Российские домены `.ru`, `.рф`, `.su` и российские IP идут напрямую, остальной трафик — через VPN (в рамках правил конкретной реализации). Цель — одновременно открывать российские и зарубежные сайты, сохраняя доступ ChatGPT к MCP-туннелям.

## Важное предупреждение: EXE не подписан

`NeonaUnified.exe` **не имеет коммерческой цифровой подписи (code signing certificate)**. Поэтому браузер, Microsoft Defender SmartScreen и Windows могут предупредить о малоизвестном приложении **как при скачивании, так и при первом запуске**. Это ожидаемо для небольшой независимой программы, но не доказывает её безопасность. Сверяйте источник и SHA-256 скачанного ZIP, при необходимости проверяйте файл антивирусом. Не отключайте защиту Windows глобально. [Подробности](docs/SECURITY.md).

Для работы TUN Windows может запросить права администратора (UAC): это отдельное стандартное системное предупреждение.

## Ограничения

- Создать два туннеля в OpenAI Platform и привязать MCP-подключения к ChatGPT нужно самостоятельно; приложение не создаёт аккаунты, серверы или ключи.
- Комплект не содержит сторонние исполняемые файлы Xray-core, OpenAI `tunnel-client`, Python и Node.js.
- Программа не подменяет Windows Location API/GPS и не гарантирует изменение геолокации браузера, кроме внешнего IP.
- Статус в интерфейсе после запуска — это последняя известная проверка, **не постоянное подтверждение доступности**.
- При закрытии GUI вызывается штатная остановка управляемых соединений; не ожидайте фоновой службы после выхода.
