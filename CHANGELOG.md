# История Neona Unified

## 1.3 — стабильная, 17.11.2026

- Подтверждена пользователем в рабочей Windows-конфигурации.
- Отключены фоновые периодические проверки VPN/MCP, автоматические переподключения и модальные окна аварийных уведомлений.
- Сохранены штатные предварительные проверки только во время запуска VPN, а также ручная проверка MCP.
- Добавлена попытка завершить устаревшую Python-службу наблюдения (только при обнаружении).

## 1.2 — исправление, заменена 1.3

- Убраны повторные сетевые проверки VPN раз в ~55 секунд; обнаружена проблема старой фоновой Python-службы.

## 1.1 — предшествующая сборка

- Исправлена возможность изменять размер окна и переносить длинные строки статуса.

## 1.0–1.0.4 — экспериментальные объединения, для установки не рекомендуются

- История неверной архитектуры с отдельным Python-менеджером и старым GUI, ошибок запуска Python и PowerShell, отсутствовавшего копирования журнала и неудобной вставки ссылок.
- Эти версии не являются текущим релизом.

## Первоначальные проекты

- Neona Split VPN 1.5 — проверенная на Windows TUN-маршрутизация RU напрямую, зарубежный трафик через VPN.
- Neona MCP Manager 0.3.5 — управление двумя защищёнными MCP-туннелями, хранение ключей и журналы.
