# Предупреждения Windows, подпись и безопасность

## Почему браузер или Windows предупреждает

**NeonaUnified.exe НЕ подписан цифровым сертификатом разработчика**. Это независимая программа, поэтому:

- Chrome/Edge могут предупреждать о редком или неизвестном ZIP/EXE уже **при скачивании**.
- Microsoft Defender SmartScreen может показывать **«Система Windows защитила ваш компьютер»** или предупреждение о неизвестном издателе **при запуске**.
- UAC может запросить права администратора для Windows TUN — это отдельный запрос разрешений ОС.

Такое предупреждение **само по себе не означает вредоносность**, но отсутствие подписи также **не является доказательством безопасности**. Устанавливайте только из репозитория автора, сравнивайте хеш и при необходимости сканируйте локальным антивирусом или средствами организации.

## Как проверить архив

Оригинальный релиз 1.3: `NeonaUnified_1.3_No_Auto_Checks.zip`.

SHA-256: `e895f6ba810f064aad3d5380dbbab8418a29fb3442c3f74be68fe14cd503e909`

PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\NeonaUnified_1.3_No_Auto_Checks.zip
```

Ожидаемые 64 символа хеша должны совпасть. Если не совпадают, **не запускайте** файл. Внутри релиза находятся исходники: их можно проверить и собрать самостоятельно из исходного кода Go.

Если Windows предлагает «Подробнее» / «Выполнить в любом случае», принимайте такое решение только после проверки происхождения файла и содержимого. **Не отключайте SmartScreen или антивирус для всей системы** ради установки.

## Что получает приложение

- Повышенные права для изменения маршрутов TUN.
- Локальное хранение настроек и ключей Windows DPAPI.
- Запуск управляемых фоновых процессов Xray и OpenAI tunnel-client.
- Локальные диагностические обращения; при старте — проверку доступности VPN и MCP.

Ограниченный доступ Windows MCP зависит от самого MCP-сервера — контролируйте разрешённые каталоги и набор его инструментов. Используйте минимальные права ключей OpenAI; сторонние аккаунты и данные пользователя не должны попадать в открытые issue, screenshots или репозиторий.

## Установочные файлы и зависимости

Репозиторий содержит код Neona Unified. В комплекте отсутствуют официальные сторонние бинарники Xray-core, OpenAI tunnel-client, Python и Node.js. Их версии и лицензии определяются соответствующими проектами и должны проверяться при установке.
