# Установка Neona Unified 1.3 в Windows

## Требования

- Windows 10/11 x64 и учётная запись с возможностью подтвердить UAC (TUN требует прав администратора).
- Подходящая VPN-подписка/узел от вашего VPN-провайдера (не путать с ключом OpenAI).
- Движок Xray с `xray.exe`, `geoip.dat`, `geosite.dat`, `wintun.dll`. В проверенном проекте применялся Xray-core 26.10.31. Движок в распространяемый ZIP не включён; приложение может предложить установку/импорт согласно собственному механизму.
- Для MCP: два созданных туннеля OpenAI Platform, официальный `tunnel-client` для Windows (в исходной конфигурации v0.0.20), два настроенных серверных профиля и зарегистрированные подключения в ChatGPT.
- Для Windows MCP-сервера: Python 3.11+ и соответствующие исходные файлы сервера; для Chrome MCP: Node.js/npx, Playwright MCP и браузерное расширение.

**Важно:** `NeonaUnified.exe` не устанавливает автоматически серверы MCP, официальный tunnel-client, Python/Node.js, платную VPN-подписку или учётные записи. Подробное создание инфраструктуры: [руководство n-fm.ru](https://n-fm.ru/chatgpt-windows-chrome-mcp-instrukciya/).

## Установка

1. Скачайте ZIP из [публичного репозитория](https://github.com/neona-fm/neona-unified/blob/main/dist/NeonaUnified_1.3_No_Auto_Checks.zip) и сохраните его в удобной папке.
2. Проверьте SHA-256 ZIP: `e895f6ba810f064aad3d5380dbbab8418a29fb3442c3f74be68fe14cd503e909`. Пример PowerShell: `Get-FileHash -Algorithm SHA256 .\NeonaUnified_1.3_No_Auto_Checks.zip`.
3. Распакуйте ZIP в **отдельную папку** (сборка не требует установки через MSI).
4. Проверьте, что Xray и MCP-инфраструктура установлены. В проверенном окружении путь к клиенту был `C:\NeonaMCP\client\tunnel-client-v0.0.20-windows-amd64\tunnel-client.exe`; приложение также пытается найти соседнюю папку `client`.
5. Запустите **`NeonaUnified.exe`** и подтвердите UAC при необходимости. Второе старое GUI или чёрное окно PowerShell запускать не нужно.
6. В едином окне укажите ссылку VPN-подписки, выберите доступный узел и сохраните настройки. Сохраните ограниченный ключ OpenAI для клиентских туннелей и токен расширения Chrome в соответствующих полях; они защищаются Windows DPAPI в локальном профиле пользователя.
7. Нажмите **«Запустить всё»**. Дождитесь последовательных этапов: проверка VPN → включение TUN и контроль системного IP → Windows MCP → Chrome MCP.
8. В ChatGPT проверьте именно **реальные вызовы обоих MCP**: список файлов в разрешённой папке Windows и список вкладок Chrome. Локальный зелёный статус порта сам по себе недостаточен.

## Если уже была Neona Split VPN 1.5

При первом запуске единая программа может перенести профиль из `%APPDATA%\NeonaSplitVPN` в `%APPDATA%\NeonaOneVPN`. Это делается для совместимости с проверенными настройками 1.5. Новую программу можно настраивать отдельно; исходную рабочую папку не удаляйте, пока не проверили соединения.

## Что останется в системе

- Профиль VPN: `%APPDATA%\NeonaOneVPN`.
- Защищённые настройки и журналы MCP: `%LOCALAPPDATA%\NeonaMCP`.
- Служебные процессы Xray и tunnel-client могут работать во время активного соединения; отдельные окна старых менеджеров не нужны.

Если Windows блокирует файл при скачивании или запуске, читайте [рекомендации по проверке источника и SmartScreen](SECURITY.md), а не выключайте защиту целиком.
